Expect the two to differ in spikiness. The node stores per-bucket RMS — average energy — while wavesurfer's default rendering draws per-bucket peak, the loudest single sample. Peak rendering is spikier and reaches full height more often; RMS is flatter and smoother. The overall envelope should still track. Each is normalized to its own maximum, so absolute heights are not comparable either.
